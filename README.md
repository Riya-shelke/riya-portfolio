# Riya Shelke Portfolio

A responsive personal portfolio website generated from the supplied portfolio content.

## Files

- `index.html` - main portfolio page
- `styles.css` - responsive styling and animations
- `script.js` - mobile navigation, scroll-to-top, and reveal animations

## How to run

Open `index.html` directly in a browser, or serve the folder using a local server:

```bash
cd riya-portfolio
python3 -m http.server 5500
```

Then open `http://localhost:5500`.

## Before publishing

1. Replace `your.email@example.com` with the actual email address.
2. Add a real resume file named `resume.pdf` in the same folder if you want the Download Resume button to work.
3. Add project GitHub/demo links if available.

## Deployment

You can deploy this folder on GitHub Pages, Netlify, Vercel, or any static hosting service.
