# Riya Shelke Portfolio

A responsive personal portfolio website generated from the supplied portfolio content.

## Files

- `index.html` - main portfolio page
- `styles.css` - responsive styling and animations
- `script.js` - mobile navigation, scroll-to-top, and reveal animations

## How to run

Open `index.html` directly in a browser, or serve the folder using a local server:

```bash
cd riya-portfolio
python3 -m http.server 5500
```

Then open `http://localhost:5500`.
